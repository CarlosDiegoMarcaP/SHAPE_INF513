CSS · Propiedades de Forma

shape-outside

Aprende a crear flujos de texto alrededor de formas geométricas personalizadas. La propiedad shape-outside define cómo el contenido adyacente se ajusta a la silueta del elemento flotante.

01

circle() - Forma Circular

Crea un flujo de texto alrededor de un círculo perfecto.

/* El texto fluye alrededor de un círculo */ .elemento {
  float: left;
  shape-outside: circle(50%);
  width: 130px;
  height: 130px;
}
Sintaxis: circle(r) / circle(r at cx cy)

¿Qué hace? El texto abraza suavemente la forma redonda. Puedes ajustar el radio con circle(60px) o porcentaje circle(50%).

Variantes: Usa circle(50% at 30% 30%) para desplazar el centro de la forma sin mover el elemento físicamente.

02

ellipse() - Forma Ovalada

Crea un flujo de texto alrededor de una elipse con dos radios independientes.

/* Radio horizontal y vertical distintos */ .elemento {
  float: left;
  shape-outside: ellipse(50% 35%);
  width: 160px;
  height: 110px;
}
Sintaxis: ellipse(rx ry) / ellipse(rx ry at cx cy)

¿Qué hace? La función ellipse() acepta dos radios: horizontal (rx) y vertical (ry), separados por espacio. Ideal para imágenes apaisadas o verticales.

Variantes: ellipse(55% 40% at 40% 50%) desplaza el centro hacia la izquierda, haciendo que el texto se acerque más al borde derecho.

03

polygon() - Forma Libre

Crea un flujo de texto alrededor de una forma con múltiples vértices personalizados.

/* Triángulo: 3 puntos definidos */ .elemento {
  float: left;
  shape-outside: polygon(50% 0%, 100% 100%, 0% 100%);
  clip-path: polygon(50% 0%, 100% 100%, 0% 100%);
  width: 140px;
  height: 140px;
}
Sintaxis: polygon(x1 y1, x2 y2, x3 y3, …)

¿Qué hace? Define una forma mediante una lista de coordenadas x y separadas por comas. Puedes crear triángulos, rombos, estrellas, hexágonos o cualquier silueta irregular.

Combinación: Usa clip-path para que el elemento visualmente adopte esa forma también. Permite efectos creativos donde el texto sigue un contorno diferente al visual del elemento.

04

inset() - Rectángulo Interno

Crea un flujo de texto alrededor de un rectángulo con bordes opcionales redondeados.

/* Inset: top right bottom left + esquinas redondeadas */ .elemento {
  float: left;
  shape-outside: inset(15px 25px 15px 25px round 20px);
  width: 150px;
  height: 120px;
}
Sintaxis: inset(top right bottom left) / inset(top right bottom left round r)

¿Qué hace? Define un rectángulo hacia adentro del bounding box del elemento, usando los cuatro lados como margin o padding. La cláusula round añade bordes redondeados.

Caso de uso: El texto se curva alrededor de las esquinas en lugar de seguir ángulos rectos. Perfecto para controlar el espacio de respiración entre la imagen y el texto.

05

url() - Forma desde Imagen

Extrae la forma del canal alfa de una imagen PNG o SVG.

/* La silueta de la imagen marca dónde fluye el texto */ .elemento {
  float: left;
  shape-outside: url("imagen.png");
  shape-image-threshold: 0.5;
  width: 140px;
  height: 140px;
}
Sintaxis: url("imagen.png") + shape-image-threshold: 0-1

¿Qué hace? El navegador lee el canal alfa de un PNG o SVG y usa esa silueta como forma de flujo. Los píxeles opacos definen dónde no puede entrar el texto; los transparentes dejan pasar el texto.

Restricción: La imagen debe servirse desde el mismo origen o con cabeceras CORS correctas. Controla la opacidad con shape-image-threshold (0.5 = solo píxeles con alpha ≥ 50%).
